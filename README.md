# 莓好计划 SweetLess 🍓

一款针对手机设计的离线优先网页小游戏：温柔记录甜食习惯、通过小挑战缓解冲动、用专注学习获得金币，装扮虚拟小猫。

## 立即体验

打开 `index.html` 就能看到界面（不同浏览器对本地文件的记录保存和安装支持可能有限）。

## 安装成 iPhone 主屏幕 App（推荐）

要使用 iPhone 的“添加到主屏幕”和离线支持，请先把 **整个文件夹** 发布到支持 HTTPS 的静态网页托管服务（例如 GitHub Pages 或 Netlify）。

一种简单的方式：
1. 解压 `SweetLess.zip`。
2. 将 `SweetLess` 文件夹中的 `index.html`、`manifest.webmanifest`、`sw.js`、所有 PNG 图标一起上传到静态托管网站。`index.html` 应位于网站入口。
3. 用 iPhone 的 Safari 打开得到的 `https://` 链接。
4. 点击 Safari 的“分享” → “添加到主屏幕” → “添加”。
5. 此后从主屏幕打开即可像独立 App 一样使用。首次联网打开后，主要功能可离线使用。

**注意：** 仅下载 ZIP 不等于已经上线；本包不包含服务器或已部署的网站链接。所有记录保存于当前设备/浏览器的 localStorage；若清除网站数据、卸载或更换设备可能丢失。建议在“设置”里定期“导出备份”。

## 功能

- **每日记录**：心情与甜食体验（允许选择“不记录”），有无吃甜食均得到相同奖励。
- **替代快乐卡**：60–120 秒小休息，完成后可选择“更轻松”“还想吃”“其实饿了”；选项不会影响奖励。
- **学习计时**：5 / 15 / 25 分钟专注，支持暂停和重置；时间累计成足迹与金币。
- **小猫养成**：经验等级、金币、服饰购买与换装；点击小猫有随机温柔话语。
- **每日心意卡**：完成任意两项关照任务后解锁，无连续打卡惩罚。
- **足迹**：最近7天学习分钟数、心情日记、小成就。
- **隐私**：无需账户，数据默认只存本机；可导出、导入、清空。

## 产品理念

这不是零糖打卡/限制饮食工具。奖励用于关注情绪、尝试新休息方式和专注过程，不与“不吃甜食”挂钩，不记录卡路里，不设断签惩罚。真正饥饿时要正常吃饭。若有频繁失控进食或持续缺乏快乐的状况，请考虑寻求专业帮助。
